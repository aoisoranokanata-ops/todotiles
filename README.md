# ToDoTiles

起動した瞬間に「何をするか」と「どこまで達成したか」が大きめのアイコンで分かる、個人用の TODO・買い物・予定管理 PWA。

- 公開先: https://aoisoranokanata-ops.github.io/todotiles/
- 構成: `index.html`（HTML/CSS/JS 全部入り）＋ `manifest.json` ＋ `sw.js`。外部ライブラリ・CDN・外部画像なし
- データ: 端末内の IndexedDB（DB名 `todotiles`）。サーバーには何も送らない。端末間の移行は設定の「書き出す／読み込む」

## 主な機能

| 画面 | できること |
|---|---|
| ホーム | 今日の達成度リング、今日やること（期限切れ＋今日の未完了）、リストのタイル（今日分の達成リング） |
| リスト | 完了スタイル3種（消える／取り消し線／チェック）、スワイプ（左＝削除・右＝完了）、ドラッグ並べ替え、サブタスク、優先度 |
| 買い物 | 品目の絵文字タイル、タップで購入済み、数量、よく買う物からワンタップ再追加 |
| カレンダー | 今日（タイムライン）／週間／月間、繰り返しの回ごとの完了 |
| 統計 | 7日・30日の完了数グラフ、連続達成日数、リスト別 |
| 設定 | テーマ、週の開始曜日、通知、JSON 書き出し／読み込み、.ics 書き出し、全データ削除 |

### クイック追加の書き方（＋ボタン）

`明日15時 歯医者` / `来週月曜 資料提出 #仕事` / `毎週月水金 ジム` / `毎月25日 家賃` / `牛乳 ×2 #買い物` / `9/30 締切` / `午後3時半 打合せ`

読み取った部分は入力欄の下にチップで出る。チップをタップするとその解釈を無効にできる。

### キーボード（PC）

| キー | 動作 |
|---|---|
| N | 追加を開く |
| Tab → Enter | タスクの編集を開く |
| Alt + ↑↓（タイルは ←→ も） | 並べ替え |
| 右クリック | メニュー（編集・完了・優先度・一番上へ・削除） |
| Esc | シート・メニューを閉じる |

## 開発

```
python -m http.server 8653 --directory todotiles
```

- localhost では Service Worker を登録しない（古いキャッシュで検証を誤らないため）。PWA として試すときは `?sw=1` を付ける
- **公開するときは `index.html` の `APP_VERSION` と `sw.js` の `VERSION` を両方上げる**。開いている端末に「新しいバージョンがあります［更新する］」が出る
- GitHub Pages は他のアプリと同じオリジンなので、`sw.js` は `todotiles-` で始まる自分のキャッシュだけを扱う

## iPhone 実機での確認ポイント

チェックを付けながら確認する。✅＝確認済み。

### A. インストールと起動
- [ ] Safari で開き、共有 →「ホーム画面に追加」。アイコンが青地に白いタイル4枚（左上にチェック）になっている
- [ ] ホーム画面から起動すると、アドレスバーのない全画面になる
- [ ] 画面上端（時計・ダイナミックアイランド）に見出しや「編集」ボタンが隠れない
- [ ] 下のタブと＋ボタンが、画面下端のホームバー（横線）に重ならない
- [ ] 横向きにしても、ノッチ側に内容が隠れない
- [ ] 機内モードにしてからでも起動でき、追加・完了ができる
- [ ] 設定 →「保存領域の永続化」が「許可されています」になる（ホーム画面に追加して何度か使った後）

### B. タッチ操作
- [ ] タスク行を左右にスワイプすると削除／完了になり、縦スクロールしたときに誤って反応しない
- [ ] ⠿ をつかんで並べ替えている間、画面がスクロールしない。画面の上下端に持っていくと自動でスクロールする
- [ ] タイルや行を長押ししても、文字選択やリンクのプレビューが出ない
- [ ] ボタンを素早く2回タップしても画面が拡大されない
- [ ] 入力欄をタップしても画面が拡大されない
- [ ] ＋ボタンで開くと、すぐキーボードが出る。シートがキーボードの上に出て、入力欄と「追加」が見える
- [ ] 日本語入力で変換を確定する Enter では追加されず、確定後の Enter（改行／送信）で追加される（買い物の上の入力欄も同様）
- [ ] 「元に戻す」のトーストが、ホームバーやキーボードに隠れない
- [ ] 月間カレンダーの日付を押し間違えずにタップできる

### C. 表示
- [ ] iOS の外観（ライト／ダーク）に追従する。設定のテーマで手動切替もできる
- [ ] 設定 → アクセシビリティ →「視差効果を減らす」を ON にすると、アニメーション（消える・縮む・紙吹雪）が止まる
- [ ] 長いタスク名・リスト名が、はみ出さずに折り返しまたは省略される

### D. データ・カレンダー・通知
- [ ] 設定 →「💾 書き出す」で共有シートが開き、「"ファイル"に保存」できる
- [ ] 設定 →「📂 読み込む」でファイルを選べ、PC で書き出したデータに置き換わる
- [ ] 「🗓️ .ics を書き出す」→ カレンダーに追加でき、時刻のある予定の通知が鳴る（アプリを閉じていても鳴る代替手段）
- [ ] 設定 →「端末の通知も許可する」（iOS 16.4 以降・ホーム画面から起動した場合のみ）→ アプリを開いたまま時刻になると通知と画面上部のカードが出る
- [ ] アプリを閉じて開き直すと、期限切れと今日の予定がホームの上部に出る
- [ ] 夜0時をまたいでアプリを開いたままにすると、日付・「今日」・カレンダーが翌日に切り替わる
- [ ] 新しい版を公開した後にアプリを開き直すと「新しいバージョンがあります」が出て、［更新する］で切り替わる。データは消えない

### E. VoiceOver
- [ ] ローターの「見出し」で画面タイトルに移動できる
- [ ] タイルが「家事、残り2件、今日の達成50%」のように読まれる
- [ ] チェックボタンが「チェックボックス、オフ／オン」として読まれ、ダブルタップで切り替わる
- [ ] シートを開いている間、背面の内容が読まれない

## 既知の割り切り

- iPhone ではアプリを閉じた状態での予約通知はできない（Safari の制約）。必要なら .ics をカレンダーに取り込んで通知させる
- クイック追加で年のない過去の日付（例: 9/25 に `9/24`）を入れると翌年として扱う
- 繰り返しタスクは、取りこぼした過去の回を溜めずに次の回へ進める
- 文字サイズは iOS の「テキストサイズ」設定には追従しない（ピンチで拡大は可能）
